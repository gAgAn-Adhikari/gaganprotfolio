# Gagan Adhikari — Portfolio

Personal portfolio website for Gagan Adhikari, a Computer Science & Engineering student specialising in Internet of Things (IoT) at Kristianstad University.

## Site features

- Editorial, responsive layout inspired by contemporary engineering and creative portfolios
- Animated hero descriptor and scrolling topic ticker
- Clickable “sneak peek” words that open contextual notes
- Project cards with category filters and accessible quick-view dialogs
- Light/dark theme toggle
- Scroll-reveal motion with reduced-motion support
- Responsive mobile navigation
- Project links to the source repositories

## Project topics showcased

- Embedded-systems lab work and microcontroller coursework
- Digital circuits: full adder and dice roller report
- C voting-system program
- Python Rock–Paper–Scissors GUI
- Python shopping-list manager
- Test-subject registry with text-file read/write
- Python social-graph exercise

Project summaries are intentionally limited to details supported by the linked repositories and files.

## Run locally

Open \`index.html\` in a browser. The site uses plain HTML, CSS and JavaScript; no build step is required. Google Fonts are loaded remotely, with system fallbacks available.

## GitHub Pages

The repository already contains a GitHub Pages workflow under \`.github/workflows/\`. Keep the static site files in the repository root so the deployment can serve \`index.html\`.
